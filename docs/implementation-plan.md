## 最小业务规则

1. JSON 保持 schemaVersion="1.0" 及原字段契约。必填字符串不能空白，A-D 四选项、Domain 1-8、Type/难度按枚举，拒绝重复 JSON 属性、重复题 ID、无题题集。未知可选字段保持前向兼容，不改变版本。
2. set.id、question.id 为稳定全局身份。相同 set.id 与规范化内容完全相同视为重复且不写入；同 ID 内容不同视为冲突；新题集引用已存在题 ID 也明确拒绝，不隐式合并。相同题干/选项但不同 ID 提示可能重复，用户仍可确认导入；整套先验证再事务写入，不部分导入。
3. 题目不可编辑，历史独立保存。会话 active → completed；选择/标记即持久化，重启可继续。题序按文件原顺序。允许多个历史会话；不自动丢弃未完成会话。
4. 学习提交单题即锁定答案并记录一次计分；重复相同提交幂等，不允许改写已提交答案。考试保存选择只作草稿，交卷事务统一判分并锁定；重复交卷幂等。
5. 完成会话时漏答计错，分母为全部题数。学习已提交题立即计入累计统计，考试交卷才计入；累计作答量指已计分题次（含交卷漏答），另列漏答量。单次统计为全部已计分题次。正确率始终附样本量，无样本显示“—”。
6. 只有学习已提交题或已完成会话能收到答案/解析/正确性；后端输出时裁剪，考试草稿 API 也不返回评分。导入预览不显示答案。学习累计统计不会纳入考试草稿。
7. 曾错题永久保留在错题历史；连续正确 3 次显示已掌握，但不删除历史。收藏与作答独立，复习从全部曾错题/收藏题创建学习会话。
8. 完整 ZIP 包含一致的 SQLite 快照、应用配置及 App/数据库/备份格式版本。恢复先离线完整校验，再在数据库事务中替换业务数据；配置保存在数据库并导出校验副本，避免跨文件原子替换。任何校验或事务失败不改变当前数据。恢复前自动保留完整安全备份，恢复成功需刷新界面。
9. 默认数据目录 %LOCALAPPDATA%\\CISSPQuizTrainer\\data；专用 CISSP_QUIZ_DATA_DIR 可覆盖用于隔离验证。不默认联网，不用真实学习库测试。
10. 使用 database/sql + 纯 Go SQLite 驱动，满足 Windows 无 CGO 构建；不加入 UI 组件库/通用 CRUD/后台任务平台。

## 验证边界

单元/SQLite 集成测试、构建、进程启动、UI 操作分别记录，互不替代。若无原生窗口控制能力，保留人工验收清单，不声称全部端到端通过。最终所有必需检查只在实际运行成功后记录通过。

## 阶段 6：题集清理迭代（用户追加授权）

范围：无练习会话引用的题集可确认删除；已有历史（包括未完成/尚未选择答案的会话）仅归档。确认区显示名称和题量，物理删除不可撤销；事务再次检查引用，不删除会话、作答和学习历史。未练习题集如有独立收藏，删除确认明确提示会一并清理该题集收藏。

归档只隐藏日常题库入口，不更改题目或历史，不改变错题/收藏/统计。提供同页“已归档”和恢复显示，禁止从已归档题集直接创建新的整套练习，但已有会话可继续，错题/收藏复习照常可用。重复导入归档题集不会解除归档。

增加显式 migration 002 和备份中的归档状态。产品内部版本 0.1.1、数据库版本 2；题集 JSON 仍为 1.0。旧版 0.1.0 / 数据库 1 备份先验证原始校验和与版本，再仅在临时副本迁移，完整验证后恢复，不修改备份原文件；新版备份不供旧应用恢复。
