# CISSP Quiz Trainer v0.1.2 使用说明

这是 Windows 11 x64 的个人离线学习工具；每人独立安装、独立保存数据，不需要账号或网络。随包 4 道原创演示题仅验证软件功能，不是官方真题。

## 首次启动

1. 将 `CISSPQuizTrainer-win-x64.zip` 解压到普通文件夹，双击 `CISSPQuizTrainer.exe`。需要系统已安装 Microsoft Edge WebView2 Runtime；无需 Go、Node 或 npm。
2. 打开“题库与导入”，点击“导入 JSON 题集”，选择同目录的 `demo-questions.json`。
3. 检查预览中的题集名、题量和提示，点击“确认导入全部题目”。
4. 在题集卡片选择“开始学习”或“开始考试”。

程序无安装器、自动更新或自动联网功能。v0.1 本地产物未代码签名，Windows 的安全提示取决于系统策略；请只使用可信来源的文件，遵循本机管理策略。

## 题集删除与归档

- 从未开始过练习的题集显示“删除题集…”。确认框会列出名称、题量，确认后永久删除题集、题目及其收藏，不能撤销；按 Escape 或点击“取消”不会删除。
- 只要任一题目被练习会话引用（包括未完成、尚未选择答案的会话），就只显示“归档题集”。后台也会在删除事务中重新检查，禁止删除这些题集。
- 归档后从“日常题库”隐藏，切换到“已归档”可查看和“恢复显示”。恢复显示后可开始整套学习/考试。
- 归档不会改变历史、错题、收藏或统计；原有未完成会话可以继续，错题/收藏复习也照常可用。重复导入不会解除归档。
- 本版不提供单题删除、批量删除或回收站。

## 学习与考试

- 学习：选择 A-D 后，点击“提交本题并查看解析”。提交后锁定本题，显示正确答案、解析及可选解释。只选择但未提交的题目，在交卷时按漏答计错。
- 考试：选择立即保存，允许前后切题和修改选择，可标记待复查；交卷前不显示答案、解析或正确性。交卷后统一判分并锁定。
- 展开“答题检查”可筛选未答、待提交（仅学习）、已标记题号；练习时默认折叠，优先显示题目，交卷后结果检查默认展开。交卷确认列出所有未完成题号，点击即可返回作答。漏答计错，单次正确率分母为全部题数。
- 题号明确显示“未答／待提交／已提交”或考试“已选”，不会在交卷前显示考试正确性。可用 Tab 切换控件、方向键切换单选项、空格/Enter 操作按钮。
- 关闭程序后，“练习记录”保留未完成会话；学习显示已提交数，考试显示已选数（仍未计分）。点击“继续”定位按原题序的第一道未完成题：学习未提交、考试未选择；全部完成待交卷时优先首个标记题，否则首题。不是记住上次浏览题号。未完成学习已提交题已经计入统计，考试草稿尚未计入。
- 已完成结果支持“本次错题（含漏答）／本次漏答”筛选，上一题、下一题在当前结果范围内切换，空范围明确提示。“重练本次错题（含漏答）”按原顺序创建新学习记录，原成绩不变；全对时按钮不可用。再次作答按新题次计入统计。
- 重复点击提交/交卷不会重复计数。总用时从开始至交卷，包含暂停与关闭程序的时间。

## 错题、收藏与统计

答错或漏答的题目自动进入错题历史。连续答对 3 次显示“已掌握”，仍保留曾错记录。收藏/取消收藏不会修改作答记录；可以从错题历史或收藏题范围启动学习复习。

“统计与备份”显示累计已计分题次、正确数、正确率、漏答数和 Domain/Type 表格。同一题多次作答分别计数，每个正确率旁都有样本量；无样本显示 `—`。本工具不预测是否通过 CISSP 考试。

## 数据目录

默认位置：`%LOCALAPPDATA%\CISSPQuizTrainer\data\`。

- `cissp.db`：全部题库、会话、作答、收藏及配置；请勿在程序运行时手工编辑/替换。
- `app.log`：本地操作错误日志，不上传。
- `backups\before-restore-*.zip`：恢复前自动保留的安全备份，需自行保存/清理。

程序窗口“统计与备份”会显示实际路径。设置环境变量 `CISSP_QUIZ_DATA_DIR` 可指定独立数据目录，用于隔离验证。一次仅运行一个应用实例；切换测试目录前先退出程序。

若原数据库已经损坏到无法打开，请退出程序并复制保留原数据目录，设置新的空 `CISSP_QUIZ_DATA_DIR` 后启动，再从完整备份恢复；不要直接删除或覆盖损坏原库。本版不会在启动时自动修复或清空已有数据库；仅执行明确版本迁移（版本 1 → 2 新增归档表，保留已有数据）。

## 完整备份与恢复

1. 点击“保存完整备份”，选择新的 `.zip` 文件名。不覆盖已存在文件。
2. ZIP 含 `cissp.db` 一致快照、`config.json` 和 `metadata.json`（备份格式、App、数据库版本及 SHA-256）。配置目前只有中文语言；不需要设置页面上的额外开关。
3. 恢复时选择该 ZIP，并在原生确认框确认替换当前全部数据。
4. 软件先验证归档、版本、数据库完整性和业务记录，然后保留恢复前安全备份，再事务替换数据。校验、安全备份或写入失败都会保留原数据。
5. 成功后界面刷新，显示恢复前安全备份路径。可以恢复此安全备份撤销本次恢复。

恢复接受当前完整备份（App 0.1.2、数据库 2、备份格式 1），兼容 App 0.1.1 / 数据库 2 和 App 0.1.0 / 数据库 1 备份，旧数据库先验证再在临时副本迁移；原备份文件保持不变。新版备份保留归档状态，旧应用不能恢复新版备份，不能把程序发行 ZIP 或单独数据库文件当备份导入。题集上限 16 MiB，备份内数据库上限 256 MiB。文件处理时不要强制结束进程；应用会拦截正在执行操作时的普通窗口关闭。

## JSON 题集契约与错误

参照随包 `demo-questions.json` 或仓库 `docs/requirements-v0.3.md` 第 7 节。schemaVersion 必须是字符串 `"1.0"`，选项为 A/B/C/D，Domain 为整数 1-8，type 与 difficulty 使用约定枚举。必填字段不能为空。错误会指出字段或题 ID；不部分导入坏题集。

- 相同题集 ID 和内容：提示重复，无需再次导入。
- 同 ID 不同内容，或新题集使用已存在的题 ID：冲突拒绝，v0.1 不覆盖、不合并。
- 不同 ID 但相同题干/选项：提示可能重复，确认后仍可导入。
- 非 JSON、未知版本、重复属性、重复题 ID、缺失字段：整套拒绝。

## 人工验收步骤（仅使用隔离数据）

从仓库根目录在 PowerShell 启动测试副本：

```powershell
$env:CISSP_QUIZ_DATA_DIR = Join-Path $PWD 'tmp\manual-source'
& '.\build\bin\CISSPQuizTrainer.exe'
```

1. 导入演示题集；再次导入观察重复提示。打开非 JSON 文件或修改副本的 schemaVersion，确认拒绝且题库不变。
2. 学习首题选 A、提交，检查显示正确答案 B；收藏首题。交卷，检查 4 题全部计入，未提交题计漏答。
3. 考试第一题选 B、第二题选 C、第三题留空、第四题选 D，交卷前均不显示解析。交卷后应为 3/4、75%、漏答 1。
4. 检查错题和收藏入口、累计 8 题次/正确 3/漏答 4、Domain/Type 样本量；收藏题复习答对不删除曾错历史。
5. 再建考试，选择/标记后关闭重启，从记录继续并核对。保存完整备份。
6. 退出应用，把环境变量改为新的 `tmp\manual-restored`，重启，恢复刚才 ZIP，核对题集、历史、错题、收藏及统计。再用损坏 ZIP 验证原数据不变。
7. 检查小窗口、125%/150% 缩放、Tab/单选方向键、原生对话框取消、重复启动及操作期间关闭行为。

已执行的自动化/界面验收范围与尚未验证项目见仓库 `docs/implementation-progress.md`。自动化后端测试不替代各台电脑上的 WebView2、系统缩放及文件对话框验证。

2026-10-01 已在隔离数据目录操作真实 Windows 窗口，验证学习提交/解析/收藏、重启续答、考试已选进度、交卷检查跳题、判分、结果筛选、错题重练和统计；正式服务备份恢复后再次启动 UI 核对数据一致。文件对话框能够打开，但自动化工具无法可靠填写其文件名，因此导入预览确认、备份文件选择/恢复确认的完整原生对话框流程仍需按上述步骤人工核验；本次用正式服务准备演示数据及执行隔离备份恢复。125%/150% 系统缩放、完整 Tab/单选方向键和操作中关闭保护未纳入本次 UI 实测。

### 删除与归档人工验收

在上述隔离目录中先导入未练习的演示题集：点删除后按 Escape 取消，核对题集仍在；再次确认删除，再导入同一文件，确认可用。开始学习但尚不提交，返回题库应仅显示归档；归档后查看“已归档”，从历史继续答题并核对解析。检查归档前后错题、收藏和累计统计一致，再恢复显示。创建包含归档状态的备份并在另一个隔离目录恢复，核对状态；有旧版备份时也验证可恢复。

### v0.1.2 练习体验验收

1. 新建学习，首题选 B 不提交，题号应显示“待提交”；筛选待提交可定位首题，记录仍为已提交 0/4。提交后显示解析、题号已提交、记录 1/4。
2. 关闭并重启，继续学习应到第 2 题；选答案但不提交再续答，仍停在第 2 题。交卷确认列出第 2、3、4 题，点击第 3 题返回，确认区收起。
3. 新建考试，首题选 B，历史立即显示已选 1/4；重启继续到第 2 题，不显示答案或正确性。首题 B、第二题 A、第三题留空、第四题 D，标记第 4 题；检查未答和标记筛选及交卷前返回按钮。
4. 上述考试交卷后应为 2/4、50%、漏答 1。错题筛选仅第 2、3 题，漏答仅第 3 题，上一/下一题遵循筛选范围。重练生成 2 题学习会话且不带原选择/标记/解析，原考试仍为 2/4。新会话提交后才增加统计。
5. 全对考试的错题筛选显示空状态，无题干且重练按钮不可用。全部已选但未交卷的考试继续时到首个标记题；没有标记则到首题。

## 本版边界

不支持 Markdown/自由文本导入、题目编辑/覆盖/单题或批量删除/合并、回收站、高级组卷、复杂图表/诊断/间隔复习、账号/云同步/协作、AI、自动更新或付费功能。没有发布远程 Release。
